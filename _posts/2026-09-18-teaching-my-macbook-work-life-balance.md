For the past few months, I’ve been using my MacBook Pro for almost everything.
Work, school, personal stuff. Basically, if I need to do something on a computer, chances are I’m doing it on this laptop.

At first, I didn’t really see a problem with that. It’s a powerful machine, and I figured I might as well use it as much as I can. But after a while, I started noticing how messy everything was becoming.

I’d be doing work, then suddenly remember something for school. I’d open a tab for that, check a message, maybe look at something personal, and before I knew it, I wasn’t really focused on work anymore.

Everything was just... there.

Work apps, school stuff, personal apps, browser tabs from completely different parts of my life. They were all living in the same space.

I looked around online, and one common suggestion was to use a separate laptop for work.

Technically, I already have one. My employer gave me a Windows laptop, but for some of the things I do, it just can’t keep up as well as my MacBook. And since I already have this machine, I wanted to see if I could make it work instead of using another laptop just for the sake of separating things.

That’s when I went back to something that has been around forever: separate user accounts.

This is obviously nothing new. macOS (and even other OSes like Windows) has supported multiple users for years, and I’ve always known the feature was there. I just never really thought of using it as a way to separate different parts of my life.

So earlier this week, I finally gave it a try.

I created two profiles.

One is **Personal**, which I use for school and anything outside work.

The other is **Work**, and I try to keep that one purely for work.

The idea was simple: whenever I’m working, I log into the Work profile and stay there. When I’m done, I log out and go back to Personal.

I also started cleaning up the apps on each profile. On my Work profile, I only keep the apps I actually need for work in the Dock. Same thing with Personal.

It sounds like such a small change, but I noticed that the apps you see in front of you actually matter.

If I see something like Messages, Discord, or another personal app while I’m working, there’s always that temptation to open it for “just a second.”

And we all know how that usually goes.

One thing I’ve been trying to be strict about is closing an app immediately if I realize it doesn’t belong in the profile I’m using.

If I’m in Work and I suddenly feel like checking something personal, I try not to.

I just tell myself I can check it later.

The first few days were honestly a little annoying.

I kept switching between profiles because I would remember something from school, or I wanted to check a personal message, or I needed a file that was on the other profile.

And every time I did that, I realized I was slowly going back to the exact same habit I was trying to fix.

So I had to be a bit more disciplined about it.

If I’m working, I’m working.

If something personal comes to mind and it’s not urgent, it can wait.

It’s only been about a week, but I can already feel some difference.

The nice thing is that switching profiles almost feels like switching environments, even though I’m still using the exact same laptop.

When I log into Work, everything I see is related to work.

When I go back to Personal, I don’t have work apps staring at me or work tabs sitting in the background.

There’s a clearer separation now.

Not perfect, but definitely better than before.

What I find funny about this is that none of it comes from some new productivity app or macOS feature. Multiple user accounts have been there all along. I just never had a reason to use them this way until now.

Sometimes the useful feature isn’t the new one.

It’s the old one you finally decided to use properly.

Right now, I’m still using the same Apple ID on both profiles. I’m thinking about separating that too at some point, although I’m not sure yet if that would be overkill.

I’m still figuring out what works for me.

But so far, I like this setup.

I guess I didn’t really need another laptop.

I just needed a way to tell myself, “You’re here to work now,” and make my laptop reflect that too.
